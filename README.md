# SentimentScope

AI-powered sentiment analysis for social media text.

## Project Overview

SentimentScope is a machine learning project that classifies text as positive or negative using Natural Language Processing (NLP).

## Planned Features

- Positive/negative sentiment prediction
- TF-IDF and Logistic Regression baseline model
- Model evaluation using accuracy, precision, recall, and F1-score
- Confusion matrix visualization
- Streamlit web interface

## Project Status

Initial setup. Model training and application development are in progress.
